# Triage labels

The skills use five canonical triage roles. This table maps each role to the
label applied in GitHub.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | The issue needs maintainer evaluation. |
| `needs-info` | `needs-info` | It awaits more information from its reporter. |
| `ready-for-agent` | `ready-for-agent` | It is fully specified and ready for an agent. |
| `ready-for-human` | `ready-for-human` | It requires human implementation. |
| `wontfix` | `wontfix` | It will not be actioned. |

When a skill names one of these roles, apply the corresponding label from the
second column.
